# Stickers

Burgundy Wire logo stickers, sold through Fourthwall (they print on demand, take payment, ship, and handle sales tax). Nothing in `merch/` is part of the website build.

## Files

| File | What it is |
|---|---|
| `burgundy-wire-diecut.png` | **The print file.** Transparent PNG, 1470x993px: the logo plus THEBURGUNDYWIRE.COM with a white die-cut border. Prints sharp up to about 5" wide. |
| `burgundy-wire-diecut-preview.png` | The print file on a light and a dark surface, for a quick look. |
| `mockups.png` | The original mockups (white, black, black with outline, die-cut). Ben picked the die-cut. |
| `source/logo-ideogram-upscale-2048.png` | The logo from Ideogram, upscaled 2x (2048x2048, on black). |
| `source/logo-transparent-hires.png` | That upscale with the black keyed out and the "SPORTS · NEWS · DC" line cropped off. |
| `source/diecut.html` | Builds the print file in a browser: adds the URL in Teko, fills interior holes, grows a smooth white border (`?border=` and `?close=` tune it), and saves the PNG. |

## On Fourthwall

- **Product:** Kiss Cut Stickers (from $2.29), cut to the design's shape on square backing. Looks like a die-cut on a laptop, at kiss-cut cost. At $5 that leaves about $2.25 after the 2.9% + $0.30 card fee.
- **True die-cut** is a separate product, from $3.78 for 2". Worth it only at $7 or more.
- Upload `burgundy-wire-diecut.png` as is. The white border is part of the art.
- Fourthwall's die-cut vinyl is white (no clear), which suits this design.

## Notes

- The logo is Ben's own (Ideogram, Aug 2026). Keep NFL logos and team names off anything sold.
- Teko (the URL font) is under the SIL Open Font License, so it's fine on merch.
